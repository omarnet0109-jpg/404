# 404 Studio — تطبيق موبايل بنظام PWA

واجهة عربية RTL لتصفح 16 لقطة من الحلقة الأولى «الشباك»، تثبيت الثلاث شخصيات، تحرير prompts محليًا، تصدير JSON، وتحميل المراجع وإرسال لقطات التوليد إلى جسر ComfyUI.

### للتجربة
- ملف البداية: `mobile-studio/index.html`
- لا تحتاج مكتبات JavaScript أو build/npm.
- يمكن نشر المجلد عبر GitHub Pages (الـWorkflow: `.github/workflows/deploy-studio.yml`).
- الوصول الحالي للمشروع: `https://github.com/omarnet0109-jpg/404/tree/main/mobile-studio`.
- رابط Pages المتوقع **بعد تفعيل Pages والنشر الناجح**: `https://omarnet0109-jpg.github.io/404/`. لا تفترض أن الرابط يعمل قبل التحقق.
- تثبيت على الموبايل: افتح الموقع HTTPS، ثم إضافة إلى الشاشة الرئيسية (من قائمة Chrome/Safari).

### حدود النسخة الأولى
- **يعمل مباشرة بدون GPU**: عرض وتعديل السيناريو محليًا، تصدير JSON، إدارة الشخصيات، حفظ مسودات على جهازك.
- **يعمل فقط مع خلفية GPU جاهزة**: رفع المراجع، إنشاء مهمة فيديو، متابعة الإنتاج، معاينة الفيديو وتنزيله.
- **غير مدمج بعد**: تحويل الحوار المصري إلى صوت، تحريك الشفايف، دمج الحلقة تلقائيًا من داخل واجهة PWA، نشر الإنتاج على خادم GPU أو ضمان جودة 4K.
- السكريبتات الموجودة في `production/` و`audio/` توفر أجزاء من هذه السلسلة، لكنها غير متكاملة بعد في زر واحد. لا تعتبر فيديو من ComfyUI الحلقة النهائية المدبلجة.

### أمان
- GitHub Pages استضافة عامة وبدون أسرار؛ **لا تضع مفاتيح/API tokens في المستودع**.
- إعداد الخادم والمفتاح محفوظان في sessionStorage ولا يتم إرسالهما إلى GitHub.
- الصور المرفوعة تذهب فقط إلى خادم الجسر الذي تختاره، ثم إلى ComfyUI المتصل به.
- مسودات المشاهد مخزنة محليًا في localStorage، فصدّرها قبل تنظيف المتصفح.
- خادم الواجهة البرمجية يحتاج HTTPS وشهادة TLS، وتوكن قوي وCORS محدود.
- حدود الإنترنت/السيرفر/GPU وتكلفتها منفصلة عن الاستضافة المجانية للواجهة.

### حماية استمرارية الشخصيات
رفع الصور في الواجهة يقبل فقط صور PNG/JPG/WEBP المطابقة **بالبايت** لبصمات SHA-256 المسجلة في [`characters/character_bible.json`](../characters/character_bible.json). استخدم الصور الأربعة الأصلية بدون إعادة حفظها أو ضغطها، لأن الملف المختلف سيتم رفضه حتى لو ملامحه متشابهة. يحد الجسر من طلبات GPU إلى 12 مهمة/24 ساعة افتراضيًا (`STUDIO_DAILY_JOB_LIMIT`) لمنع استهلاك الموارد بلا حدود، لكنه ليس نظام محاسبة مالي.

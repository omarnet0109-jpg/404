# 404 Studio — نموذج Wan 2.2 المجاني لتوليد فيديو من صور الشخصيات

## القرار

**Wan 2.2 TI2V-5B (Apache-2.0)** هو محرك الفيديو الافتراضي المفتوح المصدر لمسلسل «الحي 404». يقدر يحرك صورة مرجعية مع وصف اللقطة ويحافظ نسبيًا على المظهر، لكن **ثبات الهوية 100% غير مضمون**. الصوت المصري والـlip-sync مراحل منفصلة.

الملفات البرمجية المنفذة:
- `backend/workflows/wan22_ti2v_5b_api.json` — مخطط ComfyUI API لتوليد لقطات فيديو، موجود بالفعل.
- `production/free_wan22.py` — تشغيل حقيقي على ComfyUI **محلية** مع فحص SHA-256 للصورة، واشتراط وجود النموذج والـNodes قبل بدء GPU job، ورفض النتائج التي لا تحتوي فيديو.
- `notebooks/404_wan22_free_video.ipynb` — دفتر Colab لتجربة فيديو قصير صامت من الموبايل. **لا يشغل واجهة ويب خارجية أو نفقًا**.
- `mobile-studio/index.html` — رابط تشغيل الدفتر ومعاينة الفيديو المنزّل محليًا على الهاتف.

## المتطلبات الواقعية

ComfyUI الرسمي يذكر أن Wan 2.2 TI2V-5B يمكن تشغيله بذاكرة VRAM حوالي 8GB باستخدام offloading:
https://docs.comfy.org/tutorials/video/wan/wan2_2

لا تعني 8GB ضمان أن 8GB كافية في كل جهاز أو إصدار أو إعداد دقة.

الأوزان الثلاثة (من `Comfy-Org/Wan-2.2` على Hugging Face) إجماليها تقريبًا **18GB**: نموذج 10GB، Text Encoder 6.74GB، VAE 1.41GB. التنزيل ضخم ويستهلك مساحة ووقتًا؛ لا نضعها في GitHub.

## التشغيل المجاني من الموبايل

1. افتح دفتر [Google Colab للفيديو](../notebooks/404_wan22_free_video.ipynb) أو رابطه الجاهز:
   https://colab.research.google.com/github/omarnet0109-jpg/404/blob/main/notebooks/404_wan22_free_video.ipynb
2. اختار GPU مجانية **لو متاحة**؛ Colab لا يضمن توفر GPU أو استمرار الجلسة.
3. شغّل خطوات تثبيت ComfyUI وتحميل الأوزان. الدفتر يتحقق من المساحة ولا ينزّل الملفات عند عدم توفر GPU.
4. ارفع ملف `404_mobile_reference_assets.zip` الذي يحتوي صور المرجع الأصلية الأربع. الدفتر يتحقق من SHA-256 ولا يسمح بتبديل الوجوه أو الصور.
5. اختر ليلى (الشخصية الافتراضية)، ثم شغّل خلية تجربة الفيديو **33 فريم بدقة 352×640**. دي لقطة تشخيصية قصيرة، **مش فيديو عالي الدقة ولا 6 ثواني كاملة**. قبلها بتظهر خطوة Dry Run مجانية لا تستهلك GPU.
6. نزّل ملف الفيديو الناتج فعلًا إذا نجح النموذج، وافتحه من صفحة الإنتاج في تطبيق 404 Studio لمراجعته محليًا. لا يتم إرسال الملف إلى GitHub ولا يُنشر تلقائيًا.

### مهم: Colab المجاني ليس محرك إنتاج دائمًا للـPWA

Google تمنع الاستخدام المجاني الذي يتفاعل أساسًا عبر واجهة ويب/remote control بدلًا من Notebook UI. لذلك **لن نستخدم Cloudflare Tunnel/ngrok/SSH لتوصيل Colab المجاني مباشرة بزر PWA**:
https://research.google.com/colaboratory/faq.html

الـPWA لديها أيضًا API bridge منفصل، مجهز لاستضافة ComfyUI على GPU مملوكة للمستخدم أو مزود مدفوع **بموافقة صريحة مستقبلًا**، وعندها يشتغل زر التوليد مباشرة في التطبيق.

## معايير القبول

- إثبات وجود ملف MP4/WebM/MOV حقيقي من ComfyUI؛ لا نعد لقطة صامتة أو صورة ثابتة حلقة مكتملة.
- مراجعة الوجه/الزي/الحارة بعد التوليد يدويًا؛ SHA للمرجع الأصلي لا يضمن أن النموذج لن يغير الملامح.
- لا نُكمل إنتاج 16 لقطة أو الصوت والـlip-sync قبل نجاح الاختبار الأول.
- لا توجد API keys مدفوعة أو دفع تلقائي ضمن هذا المسار.

# خدمة GPU مجانية عامة مرتبطة بتطبيق 404 Studio

**تاريخ الربط:** 2026-11-02.

## الخدمة التي تم العثور عليها

- مزوّد الحوسبة: **Hugging Face ZeroGPU**.
- خدمة فيديو عامة قائمة (حالة الدليل وقت المراجعة: **Running on Zero**):
  [zerogpu-aoti/wan2-2-fp8da-aoti-faster](https://huggingface.co/spaces/zerogpu-aoti/wan2-2-fp8da-aoti-faster).
- النموذج: Wan 2.2 Image-to-Video A14B FP8 + Lightning LoRA.
- GPU مشتركة: الاستضافة على ZeroGPU، وليست سيرفر خاص بالمستخدم أو بملفات المشروع.
- صفحة التشغيل من 404 Studio: `/mobile-studio/free-gpu.html`.
- كود الربط: `/mobile-studio/free-gpu.js`.

## ما الذي تم تنفيذه

1. صفحة عربية داخل PWA تعمل من الهاتف دون فتح Colab.
2. اختيار واحدة من 16 لقطة وتحميل وصفها تلقائيًا من السيناريو الأصلي.
3. اختيار صورة مرجعية من الجهاز. تُعرض محليًا قبل إرسالها.
4. طلب موافقة صريحة قبل إرسال الصورة وprompt لخدمة عامة خارجية.
5. ربط JavaScript Gradio Client بخدمة ZeroGPU القائمة وإرسال طلب `/generate_video` من داخل المتصفح (الزمن 1.5 ثانية تقريبًا، 4 خطوات، Seed ثابت).
6. عرض حالة الطابور، وعرض الفيديو إن أعادت الخدمة ملفًا صالحًا، أو إظهار خطأ واضح مع رابط الخدمة مباشرة.
7. لا يتم تخزين HF token ولا مفاتيح دفع في GitHub، ولا إنشاء اشتراكات مدفوعة.

## شروط وحدود مهمة

- ZeroGPU **ليس GPU دائمًا**. وفق توثيق Hugging Face الحالي: الحصة المجانية غير المسجلة 2 دقيقة GPU باليوم؛ حساب مجاني مسجّل 5 دقائق، والتوليد يعتمد على الطابور والحصة. هذه الأرقام ليست ساعات فيديو، بل مدة حساب GPU.
- Space تابع لطرف ثالث؛ قد تتغير واجهته/أسماء API أو يتوقف، والخدمة ليست تحت سيطرة صاحب 404 Studio.
- الربط تم برمجيًا؛ **لم أجرِ توليد فيديو حقيقي على GPU نيابة عن المستخدم بعد**. لا تعتبر النتيجة مضمونة قبل اختبارها عمليًا.
- الصورة المرجعية تُرسل إلى Hugging Face فقط بعد اختيار الملف والموافقة. لا ترفع صورًا خاصة أو سرية.
- لا تتحول هذه الخدمة تلقائيًا إلى جسر ComfyUI الموجود في `backend/api.py`، ولا تدّعي حالة «المحرّك متصل» داخله. إنها مزود تجريبي مستقل ومجاني من واجهة الموبايل.
- الدقة/مدة اللقطة محدودة؛ الصوت المصري والـlip-sync غير مدمجين في خدمة Wan الخارجية.
- لضمان ثبات ملامح الشخصيات، يلزم فحص الناتج يدويًا حتى مع المرجع الصحيح.
- النسخة النهائية من المسلسل 60 ثانية تحتاج إنتاج 16 لقطة ومونتاج وحوار صوتي مع جودة ثابتة. لا يمكن ضمانها ضمن الحصة اليومية المجانية الصغيرة.

## معيار إغلاق المهمة

تجربة من موبايل المستخدم تختار لقطة sh05 وصورة ليلى المعتمدة، ترسل الطلب بعد الموافقة، وتعطي ملف MP4 حقيقيًا قابلاً للمراجعة، **دون اشتراك**. لو API العامة قيّدت الطلب، يتوفر فتح النموذج الأصلي مباشرة كمسار بديل؛ تظل المهمة غير مؤكدة في هذه الحالة.

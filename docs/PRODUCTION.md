# خطة إنتاج مسلسل 404

## الاتفاق
صاحب العمل يرسل وصف المشهد باللغة العربية. المساعد مسؤول عن تحويله إلى لقطات منظّمة، وتجهيز ملفات المشروع والكود، ومراجعة أي ناتج فعلي متاح. لا نعتبر ملفًا نصيًا أو صورة ثابتة «فيديو مولّدًا».

## سير المشهد
1. قراءة وصف صاحب العمل، دون افتراض تفاصيل قصصية غير مؤكدة.
2. تقسيم المشهد إلى لقطات قصيرة؛ كل لقطة لها عمل كاميرا ووصف عربي وprompt إنجليزي للـ video model.
3. إدخال اللقطات في `scenes/episode-NN/scene-NNN.json`.
4. تنفيذ `python studio.py plan scenes/...json` لإنتاج manifest في `build/`.
5. عندما يتوفر محرّك فيديو فعلي، يمكن تشغيل `python studio.py render ... --workflow <API-workflow.json> --url <ComfyUI address>`.
6. مشاهدة المقاطع، تصحيح اختلاف ملامح الشخصيات وتكرار اللقطات عند الحاجة، ثم مونتاج نهائي خارج هذه المرحلة.

## بخصوص محرك الفيديو
GitHub مخزن للكود وملفات المشروع، وليس GPU لتوليد الفيديو. محوّل ComfyUI في هذا المشروع **يحتاج** تشغيل ComfyUI بواجهة HTTP، ونموذج video generation متوافق، وملف workflow مصدّر بصيغة API. هذا الربط لم يتم بعد؛ لا يوجد حاليًا أي فيديو مولد.

الـ workflow يجب أن يستعمل `{{PROMPT}}` في نص وصف اللقطة، ويمكنه أيضًا استعمال:
`{{NEGATIVE_PROMPT}}`, `{{WIDTH}}`, `{{HEIGHT}}`, `{{FRAMES}}`, `{{SEED}}`.

يشترط أن يصدر ملف فيديو (.mp4 / .webm / .mov) في نتائج ComfyUI. لو صدر صورة فقط، سيوقف البرنامج المشهد بدل الادعاء أنه اكتمل.

## الأمان
- لا تحفظ مفاتيح خدمات توليد الفيديو داخل GitHub أو ملفات المشروع.
- ملفات `build/` للنتائج المحلية وغير مضافة للـ Git.
- لا يتم تشغيل محتوى أو إنفاق مدفوع تلقائيًا بدون إتاحة وإعداد المحرك وموافقة صاحب المشروع.
